# Coach Flow

Quiero crear una plataforma web moderna llamada (nombre de la app, de momento puedes poner FitFlow) enfocada en entrenadores personales online.

El objetivo principal de la plataforma es ahorrar tiempo a los entrenadores, permitiéndoles gestionar todos sus alumnos desde un único lugar, sin necesidad de utilizar WhatsApp, Excel, Google Drive o varias aplicaciones diferentes.

La aplicación debe tener un diseño moderno, minimalista y profesional, similar a Notion, Stripe o Linear, con una interfaz limpia, intuitiva y muy rápida.

La plataforma tendrá dos tipos de usuarios:

1. Entrenador

Cuando un entrenador inicia sesión debe acceder a un panel de control donde pueda visualizar rápidamente toda la información importante de sus alumnos.

El dashboard debe mostrar:

 Número total de alumnos.

 Alumnos activos.

 Revisiones pendientes.

 Alumnos que no registran actividad desde hace varios días.

 Últimos vídeos enviados.

 Últimas fotos de progreso.

 Notificaciones importantes.

 Calendario de revisiones.

Desde el panel el entrenador podrá:

 Crear nuevos alumnos.

 Editar alumnos.

 Eliminar alumnos.

 Crear programas de entrenamiento.

 Asignar entrenamientos a uno o varios alumnos.

 Crear planes de alimentación.

 Asignar dietas.

 Revisar el progreso.

 Comparar fotos del antes y después.

 Revisar vídeos enviados por el alumno.

 Escribir comentarios.

 Enviar mensajes.

 Registrar revisiones semanales.

 Consultar gráficas de evolución.

Cada alumno tendrá una ficha individual con toda su información organizada.

Plan alimenticio.

Comidas.

Notas.

Progreso

Peso.

Grasa corporal.

Medidas.

Fotos de progreso.

Gráficas.

Hábitos

Pasos diarios.

Litros de agua.

Horas de sueño.

Estado de ánimo.

Multimedia

Fotos.

Vídeos.

Chat

Conversación privada entre entrenador y alumno.

2. Alumno

Cuando el alumno inicia sesión debe tener una experiencia mucho más sencilla.

Debe poder ver únicamente la información relacionada con él.

Su pantalla principal debe mostrar:

Objetivos del día

Entrenamiento del día.

Comidas.

Objetivo de agua.

Objetivo de pasos.

Peso semanal.

Revisión pendiente.

Debe poder:

 Marcar el entrenamiento como realizado.

 Registrar pesos utilizados.

 Registrar repeticiones.

 Subir vídeos entrenando.

 Subir fotos de las comidas.

 Registrar litros de agua.

 Registrar pasos diarios.

 Registrar peso.

 Subir fotos de progreso.

 Leer comentarios del entrenador.

 Enviar mensajes al entrenador.

Diseño

Quiero un diseño premium.

Minimalista.

Mucho espacio en blanco.

Colores principales:

Blanco.

Negro.

Azul.

Detalles modernos.

Tarjetas con bordes redondeados.

Sombras suaves.

Animaciones elegantes.

Debe ser completamente responsive para móvil, tablet y ordenador.

"Olvídate de WhatsApp y Excel."

Footer profesional.

Objetivo del producto

No quiero crear simplemente una aplicación para entrenadores.

Quiero crear la plataforma que centralice absolutamente toda la gestión de un entrenador online.

El entrenador debe poder abrir la plataforma cada mañana y saber exactamente:

 Qué alumnos entrenaron.

 Quién no cumplió la dieta.

 Quién envió un vídeo.

 Quién necesita una revisión.

 Quién lleva días sin registrar actividad.

Quiero que el mayor valor del producto sea el ahorro de tiempo y la organización.

Toda la interfaz debe transmitir profesionalidad, rapidez y facilidad de uso.
